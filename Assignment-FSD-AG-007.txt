# Question 01 : 
    Write code that creates a new paragraph element with the text "Welcome
to our website!" and adds it to a div with the id "content" on the webpage. Explain what
createElement and appendChild methods do.

# Answer 01 : 
    JavaScript Code : 

// Create a new paragraph element
const para = document.createElement("p");

// Add text to the paragraph
para.textContent = "Welcome to our website!";

// Select the div with id "content"
const contentDiv = document.getElementById("content");

// Add the paragraph inside the div
contentDiv.appendChild(para);

# Question 02 : 
    You need to change the appearance of a button when users hover over it.
Write code that finds a button with id "myButton" and changes its background color to
blue and text color to white using the element.style property.

# Answer 02 : 
    JavaScript Code : 

// Select the button
const button = document.getElementById("myButton");

// Change style when mouse hovers over the button
button.addEventListener("mouseover", function() {
  button.style.backgroundColor = "blue";
  button.style.color = "white";
});

// Optional: return to normal when mouse leaves
button.addEventListener("mouseout", function() {
  button.style.backgroundColor = "";
  button.style.color = "";
});

# Question 04 : 
    Write a function named extractDomain that takes an email string like
"john@example.com" and returns the domain part ("example.com") using only
string methods. Do not use regular expressions.


# Answer 04 : 

    function extractDomain(email) {
  let atIndex = email.indexOf("@");
  let domain = email.slice(atIndex + 1);
  return domain;
}

// Example
console.log(extractDomain("john@example.com"));

# Question 05 : 
    Write a function called repeatMessage that takes a message string and
a number, and returns the message repeated that many times, separated by a space.
Do not use loops.
Example:
repeatMessage("hello", 3) should return "hello hello hello

# Answer 05 : 
    JavaScript Function : 

function repeatMessage(message, number) {
  return Array(number).fill(message).join(" ");
}

// Example
console.log(repeatMessage("hello", 3));

     Explain what the Event Loop is in JavaScript and predict the output of the
following code. Also explain why the output appears in that specific order.
console.log('Start');
setTimeout(function() {
console.log('Timeout 1');

# Answer 06 : 
    Event Loop in JavaScript :

The Event Loop is a mechanism in JavaScript that handles asynchronous operations.
JavaScript runs code in a single thread, meaning it executes one task at a time. The event loop helps manage tasks like timers, callbacks, and promises without blocking the main program.

When asynchronous functions like setTimeout() are used, their callbacks are placed in the callback queue and executed only after the main code (call stack) is finished.

Code : 

console.log('Start');

setTimeout(function() {
  console.log('Timeout 1');
}, 0);

console.log('Middle');

setTimeout(function() {
  console.log('Timeout 2');
}, 0);

console.log('End');

# Question 07 : 
    Write a JavaScript function named startCountdown that logs “Time left:
X” every second, starting from 5 down to 1, and finally logs “Time’s up!”. Use
setInterval and clearInterval only.


# Answer 07 : 
    JavaScript Function Using setInterval and clearInterval : 

function startCountdown() {
  let time = 5;

  const timer = setInterval(function () {
    console.log("Time left:", time);
    time--;

    if (time === 0) {
      console.log("Time's up!");
      clearInterval(timer);
    }
  }, 1000);
}

// Start the countdown
startCountdown();

# Question 08 : 
     Explain what Promises are in JavaScript and write code that creates a
Promise to simulate checking if a user is logged in. The Promise should resolve with
user data after 2 seconds if successful, or reject with an error message if the user is not
found.

# Answer 08 : 
    Promises in JavaScript

A Promise in JavaScript is an object that represents the result of an asynchronous operation. It is used when a task takes time to complete, such as fetching data from a server or checking user authentication.

A Promise has three states:

Pending → The operation is still running.

Resolved (Fulfilled) → The operation completed successfully.

Rejected → The operation failed.

Promises use .then() to handle success and .catch() to handle errors.

Example Code
function checkUserLogin(isLoggedIn) {
  return new Promise(function(resolve, reject) {
    setTimeout(function() {
      if (isLoggedIn) {
        resolve({ name: "Rahul", id: 101 });
      } else {
        reject("User not found");
      }
    }, 2000);
  });
}

// Using the Promise
checkUserLogin(true)
  .then(function(user) {
    console.log("User logged in:", user);
  })
  .catch(function(error) {
    console.log("Error:", error);
  });

    Rewrite the following Promise-based code to use async/await syntax. The
code fetches user data and then fetches that user's posts. Include proper error handling.
function getUserDataAndPosts(userId) {
return fetchUserData(userId)
.then(userData => {
return fetchUserPosts(userData.id)
.then(posts => {
return { user: userData, posts: posts };
});
})
.catch(error => {
console.error('Error:', error);
throw error;

# Answer 09 : 
    Code Using async/await : 

async function getUserDataAndPosts(userId) {
  try {
    const userData = await fetchUserData(userId);
    const posts = await fetchUserPosts(userData.id);

    return { user: userData, posts: posts };

  } catch (error) {
    console.error("Error:", error);
    throw error;
  }
}

# Answer 10 : 
     JavaScript Code Using Fetch API : 
     
<!DOCTYPE html>
<html>
<head>
<title>Weather App</title>
</head>
<body>

<h2>Weather Information</h2>
<div id="weather"></div>

<script>
const apiKey = 'abcd1234';

const apiUrl =
`https://api.openweathermap.org/data/2.5/weather?q=Mumbai&appid=${apiKey}&units=metric`;

fetch(apiUrl)
  .then(response => response.json())
  .then(data => {

    const weatherInfo = `
      <p><strong>City:</strong> ${data.name}</p>
      <p><strong>Temperature:</strong> ${data.main.temp} °C</p>
      <p><strong>Weather:</strong> ${data.weather[0].description}</p>
      <p><strong>Humidity:</strong> ${data.main.humidity}%</p>
      <p><strong>Wind Speed:</strong> ${data.wind.speed} m/s</p>
    `;

    document.getElementById("weather").innerHTML = weatherInfo;

  })
  .catch(error => {
    console.log("Error fetching weather data:", error);
  });
</script>

</body>
</html>
