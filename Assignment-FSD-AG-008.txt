# Question 04 : 
     Explain how props support React’s one-way data flow

# Answer 04 : 
    In React, props (properties) are used to pass data from a parent component to a child component.

React follows a concept called one-way data flow, which means data moves only in one direction: from parent to child.

How Props Support One-Way Data Flow

Parent Sends Data
The parent component sends data to the child component using props.

Child Receives Data
The child component receives the data but cannot change it directly.

Data Flow is Predictable
Since data flows only in one direction, the application becomes easier to understand and debug.

Example : 

function Parent() {
  return <Child name="Rahul" />;
}

function Child(props) {
  return <h2>Hello, {props.name}</h2>;
}

# Question 06 : 
    Given const fruits = ['Apple', 'Banana', 'Cherry'], write a
component FruitList that renders an unordered list of these fruits using .map() and
includes a key.

# Answer 06 : 
    React Component Using .map() : 

const fruits = ['Apple', 'Banana', 'Cherry'];

function FruitList() {
  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  );
}

# Question 07 : 
    Why is the key attribute important when rendering lists in React? What
goes wrong if keys are missing or misuse array index?


# Answer 07 : 
    // Importance of the key Attribute in React :

In React, the key attribute is used when rendering lists to give each element a unique identity.

Keys help React identify which items have changed, been added, or removed when the UI updates.

// Why Keys Are Important : 

Efficient Updates : 
Keys help React update only the changed elements instead of re-rendering the whole list.

Better Performance : 
React can compare elements quickly and update the DOM efficiently.

Correct UI Behavior : 
Keys ensure that each component keeps its correct state during updates.

// Problems If Keys Are Missing :

React may re-render the entire list, which reduces performance.

UI updates may become incorrect or unpredictable.

Problems When Using Array Index as Key

Using the array index as a key can cause problems when:

Items are added

Items are removed

Items are reordered

In these cases, React may mix up components, leading to incorrect data or UI behavior.

Example of Better Key Usage : 

const users = [
  { id: 1, name: "Rahul" },
  { id: 2, name: "Priya" }
];

users.map(user => (
  <li key={user.id}>{user.name}</li>
));

# Question 09 : 
    Create an App component that holds an array of numbers, passes them to
a NumberList child component for rendering, and passes a click handler function to
log the clicked number. Show one-way data flow and event handling.


# Answer 09 : 
    // Child Component : 

function NumberList(props) {
  return (
    <div>
      {props.numbers.map((num, index) => (
        <p key={index} onClick={() => props.onNumberClick(num)}>
          {num}
        </p>
      ))}
    </div>
  );
}

// Parent Component
function App() {
  const numbers = [1, 2, 3, 4, 5];

  function handleNumberClick(number) {
    console.log("Clicked number:", number);
  }

  return (
    <div>
      <h2>Number List</h2>
      <NumberList numbers={numbers} onNumberClick={handleNumberClick} />
    </div>
  );
}

# Question 10 : 
    Design a component ProductList that receives products (array of
objects with id, name, price). Render a list of product names and prices using
.map(). Each item when clicked should call a prop onProductSelect(product).
Include the proper key.

# Answer 10 : 

    function ProductList(props) {
  return (
    <div>
      {props.products.map(product => (
        <p
          key={product.id}
          onClick={() => props.onProductSelect(product)}
        >
          {product.name} - ₹{product.price}
        </p>
      ))}
    </div>
  );
}
